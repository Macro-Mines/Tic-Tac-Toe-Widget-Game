# Tic Tac Toe Widget Game 🎮

A sleek, modern Windows desktop widget and web application for Tic Tac Toe powered by Minimax AI, sound effects, and glassmorphic UI.

## Features
- 🧠 **Smart AI**: Minimax algorithm with unbeatable logic as well as customizable difficulty levels.
- 🪟 **Desktop Widget & Web Modes**: Launchable as an Electron desktop widget or played via a lightweight web server.
- 🎨 **Glassmorphism Aesthetic**: Modern glowing UI, responsive design, and smooth animations.
- 🎵 **Sound Effects & Audio FX**: Interactive sound feedback for moves, wins, and draws.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16+)

### Installation
```bash
npm install
```

### Running the App
- **Desktop Widget (Electron)**:
  ```bash
  npm start
  ```
- **Web Server**:
  ```bash
  npm run dev
  ```
